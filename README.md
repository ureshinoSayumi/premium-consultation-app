# Premium Consultation App

Expo + React Native (TypeScript) scaffold for the Premium Consultation feature.

## Prerequisites

- **Node.js** LTS (recommended: 20.x or 22.x)
- **npm** 10+
- Optional for device preview:
  - [Expo Go](https://expo.dev/go) on a phone, or
  - Android Studio emulator / Xcode simulator (macOS)

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

Then press:

- `a` — Android
- `i` — iOS (macOS only)
- `w` — Web

Or:

```bash
npm run android
npm run ios
npm run web
```

## Typecheck

```bash
npm run typecheck
```
